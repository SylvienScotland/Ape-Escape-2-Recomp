# Ape Escape 2 Recompiled (WIP)

Static recompilation of Ape Escape 2 (PS2, USA) to native PC using
[PS2Recomp](https://github.com/ran-j/PS2Recomp).

Contains no game data. You must supply your own legally dumped disc.
